# 𝕏 Twitter Clone

A full-stack social media application built using MERN - **React**, **Node.js**, **Express.js**, **MongoDB**. A feature-rich Twitter clone demonstrating modern web development practices.

## ✨ Features

- 🔐 **User Authentication** - Secure JWT-based login & signup functionality
- 📝 **Tweet Management** - Create, read, update, and delete tweets
- 👥 **User Profiles** - View and manage user profiles
- 🔗 **Follow System** - Follow and unfollow other users
- ❤️ **Interactions** - Like, unlike tweets and comment on post/tweets
- 📱 **Responsive Design** - Works seamlessly on all devices

## 🛠️ Tech Stack

**Frontend:**
- React - UI library
- Vite - Fast build tool
- Tailwind CSS And DaisyUI - Styling 

**Backend:**
- Node.js - Runtime environment
- Express.js - Web framework
- Cloudinary- for Image uploads
- JavaScript (ES6+)
  
**🔐 Security:**
- Password hashing with bcrypt
- JWT token-based authentication
- CORS configuration
- Input validation
- Protected API routes

### Setup .env file

```js
MONGO_URI=...
PORT=...
JWT_SECRET=...
NODE_ENV=...
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...
```

### Build the app

```shell
npm run build
```

### Start the app

```shell
npm start
```
